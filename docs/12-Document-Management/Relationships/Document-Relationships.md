# Document Relationships

Documents form a project knowledge graph.

## Relationship Types

- depends-on
- references
- implements
- supersedes
- derived-from
- related-to

## Example

DOC-ERP1001-001

- references -> DOC-ARCH-001
- implements -> ERP-1001.Domain
- implements -> ERP-1001.Application
- implements -> ERP-1001.Infrastructure
- related-to -> DOC-API-001
